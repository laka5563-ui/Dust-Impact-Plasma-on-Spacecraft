# Dust Impact Plasma Plume Magnetic Field Model

## Overview

This project models the magnetic field generated by a plasma plume formed after a hypervelocity dust impact on a spacecraft and uses an inverse modeling framework to estimate the impact location from magnetic field measurements.

The model simulates impact-generated plasma dynamics and computes the resulting transient magnetic field at a search-coil magnetometer (SCM). An inverse solver is then used to determine the most likely impact point on the spacecraft surface.

---

## Physics Background

When a dust particle impacts a spacecraft at hypervelocity:

* A dense plasma cloud of ions and electrons is generated
* Electrons expand faster than ions, creating charge separation
* Plasma expansion drives transient currents
* These currents generate measurable magnetic field disturbances

The magnetic field is approximated using a simplified Biot–Savart formulation:

[
B \propto \frac{I \times r}{r^3}
]

where:

* ( I ) = plasma current
* ( r ) = vector from impact location to sensor

---

## Key Features

* Plasma plume modeling using:

  * Ion population representation
  * Cosine (Lambertian) angular distribution
* Gaussian velocity distribution (implemented as temporal broadening)
* Magnetic field computation using Biot–Savart law
* Time-varying magnetic field simulation:

  * ( B_x, B_y, B_z ), and ( |B| )
* Inverse modeling for impact localization on spacecraft surface
* Validation framework including:

  * Forward model consistency check
  * Top-5 solution clustering
  * Residual error distribution mapping
  * Sensitivity testing
* Ion estimation from magnetic signal

---

## Model Description

* The spacecraft surface is represented as a triangular mesh
* Each triangle is treated as a candidate impact location
* For each candidate:

  * Magnetic field is computed at the SCM
  * Model is scaled to match measured signal
  * Residual error is calculated
* The location with minimum error is selected as the estimated impact point

The plasma velocity distribution is modeled using a Gaussian distribution, which introduces a spread in ion arrival times and results in realistic signal broadening.

---

## Outputs

The model produces:

### Magnetic Signal

* ( B_x(t), B_y(t), B_z(t) )
* Magnetic field magnitude ( |B(t)| )
* Peak time detection

### Inverse Solution Results

* Estimated impact location (X, Y, Z)
* Distance from SCM
* Residual error
* Top candidate solutions

### Visualization

* Time-series magnetic field plot (PSP-style waveform)
* Top-5 solution cluster (3D)
* Residual error distribution map (3D)

---

## Assumptions

* Plasma expansion is collisionless
* Magnetic field modeled using simplified Biot–Savart relation
* Gaussian velocity distribution approximates ion dispersion
* Spacecraft–plasma interactions are simplified
* Single SCM sensor is used (inverse problem is under-constrained)

---

## Limitations

* Does not include full particle-level plasma simulation
* No explicit modeling of:

  * plasma recombination
  * spacecraft charging
  * shielding effects
* Gaussian velocity model is an approximation
* Single-sensor setup limits uniqueness of solution
* Signals are PSP-inspired, not directly ingested from raw spacecraft datasets
